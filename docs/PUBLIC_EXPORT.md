# Public export policy

This directory was produced by the Portfolio Foundry **GitHub Showcase** projection.

Excluded on purpose:

- raw ChatGPT/AI authoring requests and responses;
- transient stage progress/checkpoint caches;
- nested candidate/evidence ZIP archives;
- Python bytecode, build output, virtual environments and editor caches;
- local 19B build/runtime traces; the public success screenshot `УСПЕХ/УСПЕХ.png` is intentionally retained;
- machine-specific absolute user paths (sanitized to placeholders where a retained proof/config needs the value shape);
- credentials/tokens/private keys (publication is blocked if common secret patterns are detected).

The projection keeps the runnable source, tests, runtime contracts, minimal sealed proof manifests and concise proof summaries required to explain what actually executes.
