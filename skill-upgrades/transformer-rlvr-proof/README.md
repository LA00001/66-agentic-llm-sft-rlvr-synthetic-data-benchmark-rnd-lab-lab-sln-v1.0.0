# Локальный proof: RLVR-подобное обучение Transformer policy

Доказано локально: небольшой Transformer на PyTorch выполняет детерминированные стратифицированные групповые rollout-ы по полному дискретному action-space, получает точную проверяемую награду от арифметического oracle, вычисляет group-relative advantage и реально обновляет параметры policy градиентным шагом. Измеряются baseline/final accuracy, число rollout-ов, положительные reward и факт изменения параметров.

Ремонт попытки 2 устраняет нестабильность предыдущего stochastic sampling: baseline фиксируется нулевой инициализацией выходной головы, а каждая группа содержит все пять допустимых действий ровно по одному разу. Это не меняет исходные acceptance criteria из test_skill.py: требуется PASS, не менее 100 rollout-ов, наличие положительных reward, фактическое обновление параметров, final accuracy не ниже 5/6 и строго выше baseline.

Ограничение: это компактная локальная демонстрация RLVR/GRPO-подобного механизма на малой Transformer policy, а не post-training большой LLM, не специализированный production RL-стек и не доказательство production-scale инфраструктуры.
