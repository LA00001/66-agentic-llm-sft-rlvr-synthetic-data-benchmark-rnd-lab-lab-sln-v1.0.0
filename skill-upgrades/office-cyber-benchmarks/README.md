# Локальный proof: office и cyber benchmark-oracles

Доказано локально два исполняемых доменных сценария, которых не хватало специализированному benchmark harness:

- **Office:** обработка табличного CSV-сценария, построение проверяемого результата, упаковка реального ZIP-артефакта отчёта и повторная oracle-проверка его содержимого.
- **Cyber:** разбор журнала аутентификации и детерминированный oracle для обнаружения серии неуспешных входов по одному пользователю и IP.

Оба сценария имеют конкретный ожидаемый ответ, исполняются без внешних сервисов и дают машинно-проверяемый PASS.

Ограничение: это компактные локальные benchmark-задачи, а не полноценные Office-продукты, SIEM, CyberGym или инфраструктура киберполигона.
